내가 만든 CLI 도구의 README를 새로 써 줘. 도구 이름은 qa-rec, Google 시트에 적힌 상담 번호로 녹취 파일을 찾아 내려받는 Python 스크립트야. 설치는 pip install -r requirements.txt, 실행은 python qa_rec.py --sheet <시트ID> --month 2026-10, 결과는 ./downloads/ 폴더에 wav로 저장돼. 환경변수 QA_REC_TOKEN이 필요해. GitHub에 공개할 거라 처음 보는 사람도 쓸 수 있게 써 줘.
